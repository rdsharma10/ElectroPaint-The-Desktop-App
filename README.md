# 🖌️ Whiteboard Canvas

A cross-platform **Whiteboard Drawing Application** built using **Electron.js**, combining the power of Chromium and Node.js. Designed for simplicity, performance, and real-time responsiveness — ideal for sketching, brainstorming, or collaborative note-taking.

## 🚀 Features

- 🎨 **Canvas Drawing Tools** – Draw freehand with smooth stroke rendering
- ⚡ **Optimized SQL Operations** – Over 50% faster query handling for efficiency
- 🔄 **Cross-Platform Support** – Seamless performance on **Windows**, **macOS**, and **Linux**
- 📂 **Load / Save Canvas State** – Save your work locally and restore when needed
- 📦 **Electron-Powered** – Combines Chromium rendering with Node.js backend
- 📈 **9% Performance Boost** – Native-like experience via memory and render optimizations
